# Language

The learner using this repo writes in Chinese and reads English. The app itself
teaches English, so the working language of the project is English.

- Answer in English no matter which language the request is written in.
- After an advanced English word or phrase, add a short Chinese gloss in
  parentheses when it genuinely aids comprehension — 熟练度 (familiarity),
  渐进显示 (progressive reveal). Do not gloss ordinary vocabulary; it becomes
  noise.
- Code, comments, commit messages and UI copy are English only.
